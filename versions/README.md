# Versions Archive — ITEA Framework

This folder preserves prior published versions of the ITEA Framework alongside
the source documents that were consolidated into the active v3.0 release.
Active v3.0 artefacts live in the repository root, under `docs/`, `data/`
and `code/`.

## Layout

| Path | Contents | Notes |
|------|----------|-------|
| `v2.0/` | Methodology (EN/ES) and `Research_Data_Workbook_v2.0.xlsx` | First widely-circulated stable release. |
| `v2.1/` | Update memo (`Anexo_…_Memo_Actualizacion_v2.1.docx`) and `Research_Data_Workbook_v2.1.xlsx` | Patch release; the annex memo documents the deltas applied on top of v2.0. |
| `v3.0_originals/` | Pre-consolidation v3.0 sources (Methodology EN, Memo ES, Consolidated source, Workbook source) | Byte-identical to the active v3.0 files in `docs/` and `data/processed/`; kept here for provenance. |
